# Third-party components — `@regulait/model-provider`

Open-source components this package ships or uses in its tests (ADR-0176 admission rules: MIT, Apache-2.0, BSD or
ISC; maintained; pinned; works air-gapped). npm dependencies are pinned exactly through `pnpm-lock.yaml`.

| Component | Version | Licence | Used for, and why |
|---|---|---|---|
| `@anthropic-ai/sdk` (npm, github.com/anthropics/anthropic-sdk-typescript, © Anthropic) | `0.113.0` (exact) | MIT | Anthropic Messages API client behind the Claude adapter in `src/index.ts`; base URL is configurable so BYOC/air-gapped deployments can point it at a private gateway. |
| `openai` (npm, github.com/openai/openai-node, © OpenAI) | `6.49.0` (exact) | Apache-2.0 | OpenAI-compatible chat/completions client behind the GPT and OpenAI-compatible adapters in `src/index.ts`; base URL is configurable for self-hosted and open-weight endpoints. |
| `@hyperjump/json-pointer` (npm, github.com/hyperjump-io/json-pointer, © Jason Desrosiers) | `1.1.3` (exact; released 2026-10-03) | MIT | ADR-0241 (P21): RFC 6901 JSON Pointer parsing and resolution for the admin-defined usage mapping in `src/usage-extractor.ts`, so pointer syntax, `~0`/`~1` escapes and array indexing are not hand-written. It reads own properties only (`Object.hasOwn`), so a pointer cannot reach a prototype. No dependencies, no install script, no runtime network use. Chosen over `jsonpointer` and `json-pointer` (no release since 2022, failing the maintenance rule), `json-ptr` (no release since 2022) and a JSONPath library (filters and script expressions are more than a bounded mapping needs; `jsonpath-plus` is in the lockfile only through `@kubernetes/client-node`). Version 1.1.3 rather than 2.0.x or 1.1.4, which were released in the week of adoption. |
| `@ai-sdk/provider` (npm, github.com/vercel/ai, © Vercel) | `4.0.35` (exact; released 2026-10-30) | Apache-2.0 | The AI SDK's vendor-neutral language-model specification (LanguageModelV4) that `src/ai-sdk-bridge.ts` maps our dispatch contract onto (ADR-0253). Types plus `APICallError`; no network code. |
| `@ai-sdk/google` (npm, github.com/vercel/ai, © Vercel) | `4.0.109` (exact; released 2026-10-30) | Apache-2.0 | Gemini implementation of that spec behind the Google adapter in `src/google-ai-sdk.ts`, replacing our hand-written raw-fetch adapter (ADR-0176 rule 2, ADR-0253). Base URL, key and guarded fetch are always passed explicitly; no telemetry (that lives in the `ai` core, which we do not install). |
| `@ai-sdk/provider-utils` (npm, transitive via `@ai-sdk/google`, github.com/vercel/ai) | `5.0.72` (exact, lockfile; released 2026-10-30) | Apache-2.0 | HTTP/JSON/SSE helpers the Google implementation calls; every request goes through the `fetch` we inject. Its `undici` download helper is only used for URL-referenced files, which our bridge never produces. |
| `undici` (npm, transitive via `@ai-sdk/provider-utils`, github.com/nodejs/undici) | `7.30.2` (exact, lockfile) | MIT | Loaded lazily by `@ai-sdk/provider-utils` for URL file downloads only; not on any path this package uses. |
| `@standard-schema/spec` (npm, transitive via `@ai-sdk/provider-utils`, github.com/standard-schema/standard-schema) | `1.1.0` (exact, lockfile) | MIT | Type definitions for the Standard Schema interface the provider utilities validate against; types only, no runtime I/O. |
| `@workflow/serde` (npm, transitive, github.com/vercel/workflow) | `4.1.0` (exact, lockfile) | Apache-2.0 | Serialization symbols the AI SDK classes declare; no I/O. |
| `eventsource-parser` (npm, transitive, github.com/rexxars/eventsource-parser) | `3.1.1` (exact, lockfile) | MIT | Parses Gemini's SSE stream for the streaming path. |
| `json-schema` (npm, transitive via `@ai-sdk/provider`) | `0.4.0` (exact, lockfile) | AFL-2.1 OR BSD-3-Clause (BSD-3-Clause elected) | Imported for its TypeScript types only; no runtime code reaches it. Unmaintained since 2021, accepted because it is type-only. |

| `vitest` (npm, github.com/vitest-dev/vitest, © Anthony Fu and contributors) | `4.1.11` (exact devDependency) | MIT | Test runner for the `*.test.ts` files in `src/`; test-only, never in a shipped bundle. |
