# Third-party components — the content-extraction image (`engines/contentextract`)

Open-source components the content-extraction image ships (ADR-0362; ADR-0176 admission rules: MIT, Apache-2.0, BSD or
ISC, or a public-domain dedication; maintained; pinned; works air-gapped). The Python closure is pinned by
`engines/contentextract/requirements.txt` (every wheel by version and sha256) and installed with
`pip install --require-hashes --no-deps --only-binary :all:`. Facts were read from the pinned wheel on 2026-11-17.

**Admission status: NOT ADMISSIBLE YET.** The image has not been built where its digest can be reported (CI's engine
image workflow builds it once the engine is registered, ADR-0362 slice 1b), the image-level scan (OS layer,
vulnerabilities, licences) has not run, and the components bundled inside `libpdfium.so` whose licences are permissive
but outside the ADR-0176 list (below) await an owner decision. No manifest entry exists yet, so nothing can enable it.
