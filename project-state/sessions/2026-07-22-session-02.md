## Lessons worth not re-learning
- `aws configure sso` / `aws sso login` require CLI v2 — check the installed version before
  assuming either works.
- AWS Organizations trusted-service enablement (CloudTrail) and delegated-admin registration
  (GuardDuty, Security Hub) are two *different* mechanisms with no single Terraform resource that
  covers both — check both per-service before assuming an org-wide config resource will just work.
- Never `TaskStop`/kill a running `terraform apply` without expecting a stale state lock
  afterward — `force-unlock` was needed every time this happened.
- Git Bash's `/tmp` is invisible to native Windows binaries invoked from the same shell — write
  temp files Windows tools need to read next to the script instead.
