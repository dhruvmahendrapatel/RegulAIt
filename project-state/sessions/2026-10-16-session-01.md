## Outcome
- Owner decision C (ADR-0190): a person's own stdio call (no agent) stays L3 by default. An admin may lower it to L2
  for interactive sessions only (never an API key), per server or project, audited with step-up. Engines are never
  treated as unknown agents. The relaxation itself is not built yet.
- I4 follow-ups: the executor reaches the gateway through a Caddy `executor-front` on `engines`, which issues from a
  stack-local CA that the executor pins. The compose `REGULAIT_TLS_HOST` default is now the neutral
  `set-regulait-tls-host.invalid`. A new import-cycle CI job runs a dependency-cruiser ratchet (baseline 74 edges,
  which may only shrink) and a contained load-alone smoke check of each module under `unshare -rn`.
- B8: `docs/ops/BOM_VERIFICATION.md` and `docs/ops/RECEIPT_V2_CUTOVER.md`. The verifier no longer passes a bundle
  when the receipt v2 boundary is absent; it refuses it. Each step is marked executed or pending execution (M-041).
- S9: SPIFFE trust bundles move from an environment variable (now ignored) into audited, never-deleted storage
  (0199), with admin routes and a UI card. X.509-SVID client authentication works end to end. Revocation is final:
  the issuing transaction locks the domain's bundle rows, and the live-chain rule is the backstop. ADR-0188's rollout
  (S0-S9) is complete.
- I5: engine tasks run only through executor placement (0200 adds `engine_runs.task_placement_id`). A result is
  refused without a placed task. The sandbox's gateway channel allows only the model routes. First-enable works from
  an executor attestation.
- Latest migration on main: 0200.
