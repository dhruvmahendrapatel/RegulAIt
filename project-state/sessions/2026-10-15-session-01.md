## Outcome
- S7: engine runners and PDP clients authenticate with `private_key_jwt` and DPoP-bound self tokens. The `rge_`
  runner token is gone and every live `pdp` virtual key is revoked. Every live runner was revoked and must re-enrol
  once.
- S8: a server with `identity_propagation = signed_assertion` gets a signed assertion per call, with a pairwise `sub`
  and pairwise agent ids. #381 adds the per-server `disclose_agent_workload_ids` opt-in. It is off by default; turning
  it on is a `settings_relax` step-up, audited and reset by a URL move.
- I8: `regulait.decision-facts.v2` and `regulait.decision-bom.v2` add `execution`. 0197 widens both version CHECKs to
  admit v1 and v2; stored v1 rows stay valid, and nothing is back-filled. The AI BOM stays `regulait.ai-bom.v1` and
  must stay verifiable.
- I4: a `runsc` backend in `packages/sandbox-executor`. stdio MCP servers no longer spawn in the gateway; they run in
  sandboxes and speak MCP over the executor channel. A governed stdio call's `execution_placements` row is written in
  its decision's transaction and keyed to that decision's audit id. Later reports are linked rows in
  `execution_placement_reports` (0198).
- Mocked UI CI runs in 5 shards (was 3).
- Latest migration on main: 0198.
