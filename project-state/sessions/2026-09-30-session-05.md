MCP approvals now record preview provenance and consent scope, preserve project
attribution, and do not reuse pending legacy rows without that metadata. Queue
presentation includes server/project labels after existing visibility checks.
The migration leaves unknown history unknown.

One action-review dialog is used by personal Inbox, admin Approvals Queue and
Review Workbench. It presents recorded/effective payloads as literal text,
credential masking, consent scope, expiry and binding details. Legacy,
malformed and expired rows cannot be approved through these screens; denial
remains possible. Bulk approval requires a review keyed to the current action
and policy binding. This local workflow safeguard is not a server attestation
that a human inspected the payload; runtime authorization and atomic consent
consumption remain authoritative.

Long payloads scroll with decision controls retained in the footer. The dialog
traps keyboard focus and restores it on Escape. Other approval kinds retain
their existing workflows; the shared Modal gains only an optional className.
