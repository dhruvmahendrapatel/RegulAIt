# Third-party runtime dependencies added deliberately

One line per dependency added under the owner's direction (2026-10-05) to prefer proven, permissively
licensed open source over hand-written code for standard problems. Each works offline (no runtime
network calls), so an air-gapped deployment is unaffected.

| Package | Version | Licence | Why |
|---|---|---|---|
| `standardwebhooks` | 1.1.1 | MIT | Signs outbound webhooks per the Standard Webhooks specification (`webhook-id`, `webhook-timestamp`, `webhook-signature`, `whsec_` secrets), so receivers verify with any off-the-shelf library (ADR-0173 batch 2b). Its transitive dependencies are `@stablelib/base64` 1.0.1 (MIT) and `fast-sha256` 1.3.0 (Unlicense, a public-domain dedication). |
| `diff` | 9.0.0 | BSD-3-Clause | Line diff of two prompt-registry commits' templates (ADR-0173 batch 2b). No dependencies. |
| `re2js` | 2.8.6 | MIT | Linear-time regular expressions (a pure-JavaScript port of RE2) as Ajv's `code.regExp` engine, so a user-supplied JSON Schema `pattern` / `patternProperties` in the playground or a prompt commit cannot stall the event loop (ReDoS), ADR-0173 batch 2b. No dependencies, no install script, no native build and no runtime download; the native `re2` binding was rejected because its install downloads a prebuilt binary (or compiles one), and `re2-wasm` has had no release since 2022. |
| `jose` | 6.2.12 | MIT | Verifies the Teams Bot Framework's Bearer JWT (`jwtVerify`) against the JWKS named by the workspace's OpenID metadata (`createRemoteJWKSet`, with its key-set cache and unknown-key refresh), ADR-0173 batch 2b. Already in the lockfile through `openid-client`; now a direct, exact-pinned dependency. No dependencies. Its only network use is the key-set fetch, which goes through our egress-guarded fetch (`customFetch`), so with no allow entry it makes no call. |
| `simple-statistics` | 7.12.1 | ISC | TEST-ONLY (devDependency): the oracle the KRI percentile test checks Postgres `percentile_cont` against (`quantile`, linear interpolation), ADR-0173 batch 2c. Nothing at run time: production percentiles are computed by Postgres. No dependencies. |
| `csv-stringify` (via `@regulait/shared`, not a direct dependency) | 6.9.0 | MIT | Formats each row of the audit-log CSV export (`GET /v1/audit.csv`) and the annotation-queue export through the shared `csvRecord`, with `escape_formulas` (OWASP CSV injection), replacing two hand-written escapers (ADR-0173 batch 2c fix round A). The streaming loop stays `csv-export.ts`. No dependencies. |
| `otpauth` | 9.5.2 | MIT | TOTP code generation and the per-step constant-time check (`HOTP.generate`, `HOTP.validate`), the step counter (`TOTP.counter`) and base32 secrets (`Secret`), replacing the hand-written RFC 4226/6238 and base32 code in `totp.ts` (ADR-0183 batch 2.1, ADR-0181 follow-up). RegulAIt keeps only the ±1-step window, the replay rule and the byte-exact enrolment URI. Its one dependency is `@noble/hashes` 2.4.0 (MIT); under Node it uses `node:crypto` for the HMAC. No install script, no runtime download. Latest release 2026-09 (maintained). |
