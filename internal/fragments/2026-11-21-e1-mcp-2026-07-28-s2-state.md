**2026-11-21 - MCP 2026-07-28 stateless protocol, slice 2 ([ADR-0311](../decisions/0311-mcp-2026-07-28-conformance.md) decision 4; lane E1, branch `builder/e1-mcp-2026-07-28-s2`, on top of slice 1).**
The 2026-07-28 path on `POST /mcp/:serverId` now serves the governed non-tool methods:
- `resources/list`, `resources/templates/list`, `resources/read`, `prompts/list`, `prompts/get` and
  `completion/complete` call the same governed function as the 2025-era path (`protocolCallForCaller`), so the org
  switch, entitlements, data scopes, approvals, scans, provenance and audit cannot differ;
- capabilities are the 2025-era ones of the enabled methods, minus `logging`; `server/discover` still opens no
  upstream;
- the SDK re-codes resource-not-found to `-32602` and adds the cache fields; only `tools/list` is sorted;
- progress is relayed on the request's own response stream; upstream log lines are never relayed on this path;
- methods the revision removed (`logging/setLevel`, `ping`, `resources/subscribe`, ...) answer `-32601` and are now
  audited (`mcp-method-unsupported`, `answeredBy: "sdk"`).
