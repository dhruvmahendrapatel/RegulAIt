**2026-11-17 - lane E34 PR 2: governed MCP tools from a customer's OpenAPI document or REST endpoint list ([ADR-0353](../decisions/0353-governed-openapi-mcp-tools-and-pluggable-routing-classifier.md) part 1).** `POST /v1/openapi-tool-sources` creates an `openapi` MCP server (a new transport, off until an admin enables it) and stages every generated operation; nothing is served until an admin approves an operation (a stepped-up compare-and-set on the reviewed digest, which also approves its ADR-0246 pin) and a user is granted the tool. The server is in-process (SDK `InMemoryTransport`), so admission scanning, definition pinning and the governed call path apply unchanged; each call is validated, built with `mcp-from-openapi` 2.9.1's pure request builder against the admin's base URL and sent through the guarded fetch with the server-held ADR-0204 credential.
