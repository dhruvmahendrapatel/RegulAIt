# Session 15 — 2026-08-13 — The brand package and the UI Structures contract

Append-only. Never edited retroactively.

## What was asked for

> *"I have attached the branding as a zip and the UI structures that we use for regulait apps,
> please make sure this app also follows the 2."*

Two standards, delivered as a zip plus an artifact URL.

## The conflict that wasn't

The zip contained **two** design systems, and they are visually incompatible on every axis:

- an **"Organic"** system — cream ground `#f5ead8`, terracotta and sage accents, Caprasimo display,
  16px radii growing to pills;
- the **regulAIt Brand Guidelines v1.0** — Graphite ramp, Signal Cyan `#00b9d4`, Gantari / Figtree /
  IBM Plex Mono, "A Secure Shield Labs product".

The instinct was to stop and ask which governs. Reading the third artefact first made the question
answer itself, and the evidence is decisive rather than a preference:

- The **UI Structures** document is titled *"UI structures for **regulAIt apps**"*, states outright
  that *"the brand package gives you colour, type and the mark"*, and is itself **rendered in
  Gantari/Figtree/IBM Plex Mono over Graphite and Signal Cyan** — it is built out of the package it
  points at.
- The Organic bundle ships its own `theme.json`, a `templates/` directory and component pages, and
  **names no product**. It is a generic design-system export that travelled in the same archive.

Two regulAIt artefacts agree with each other; the third disagrees with both. So Organic is not
adopted, and ADR-0075 §1 records *why* rather than merely *that* — the point being that if the owner
did intend Organic, the ADR is a single thing to supersede and the change is values-only.

The documents also settle their own precedence, so it never needed adjudicating:

> *"the brand package wins on colour, type and the mark. This document wins on structure and markup
> contracts."*

## What made this cheap, and it was not luck

Before planning anything, a survey: **zero hardcoded hex outside `src/theme/`**, across every CSS
module and every `.tsx`. Every colour in the SPA already flowed through a token.

That single fact set the whole scope. The palette could be replaced from one file, with **no
component edits**, and the 86 existing Playwright assertions were never at risk. The `--rg-*` names
from the contract were added as the canonical layer and the SPA's original names kept as
one-directional aliases, so ~500 call sites keep working while they migrate.

Worth stating plainly: this is the pay-off of token discipline enforced in earlier waves. Had those
sessions inlined hexes, this would have been a multi-day rewrite of 65 routes instead of one file.

## Fonts, and a constraint that turned out to be two constraints

The token contract requires the typefaces be *"Self-hosted — no CDN, no network dependency"*. That
is a brand rule; it is **also an ADR-0062 requirement**, because an off-origin font request would
break the air-gapped deployment mode. The two land on the same answer, which is a good sign.

Gantari and Figtree are variable fonts, so one woff2 each covers the full weight range — four files,
~90KB total, imported through Vite so they are fingerprinted and resolved against `base`. A spec
asserts the page fetches **nothing** off-origin.

## The accessibility contract, made executable — and what it caught

UI Structures lists seven invariants and asks for them to be asserted in CI. They now are, in
`apps/web/e2e/brand-contract.spec.ts`, **driven in a real browser rather than checked against CSS**.

That is the entire point. The document's own Traps section records a page that returned **HTTP 200
while rendering its full markup into a zero-height container**. A stylesheet assertion would have
passed it. So the spec asserts `main#rgMain` *resolves to a non-zero box*, and asserts the skip link
is genuinely the first tab stop by *pressing Tab* — not that the element exists.

**Two things went wrong while writing it, and both are the useful part of this session.**

### 1. A priming click invalidated a focus test, and I nearly "fixed" correct code

The first draft clicked the page before pressing Tab. It failed: focus landed on the nav filter, not
the skip link. The diagnosis was that Chromium drops off-viewport `translateY` links from the tab
order — plausible, and **wrong**. I changed the skip-link CSS to the clip-rect pattern and wrote a
comment asserting that Chromium behaviour as fact.

It still failed. The real cause: **clicking sets the document's *sequential focus navigation
starting point***, so Tab resumed from the sidebar and skipped everything before it — including the
link. A fresh navigation leaves no starting point, which is also the state a real keyboard user is
in. Removing the click made it pass, on both the old CSS and the new.

The clip-rect version was kept (it is the more conservative idiom), but **the comment claiming
Chromium drops translateY links was deleted** rather than shipped. A false explanation in a code
comment is worse than none: it is the thing the next person reasons from.

The lesson generalises past this bug: *the test failed, so the code must be broken* is an
assumption, not an inference. Verify which of the two is wrong before changing either.

### 2. The wordmark check passed, for the wrong reason

The brand's Don't list forbids writing "Regulait", "regulait" or "RegulAIt". The spec checking this
**passed on its first run** — and it was passing vacuously, twice over:

- the route list did not cover the pages carrying the offending copy, and
- a word-boundary regex let **"RegulAIt-LLM"** through on the trailing hyphen — a user-visible admin
  nav label, present on every admin screen.

Tightening both (capitalised misspellings flagged unconditionally; all-lowercase `regulait` still
allowed inside `admin@regulait.local` and the `/admin/regulait-llm` URL) made it fail on **14 of 15
routes**. Only then was it worth fixing the copy.

This is the same failure as ADR-0072's three scoring inversions, in a different costume: *a green
assertion is evidence of nothing until you have seen it go red.*

### 3. The contrast ratios I wrote by hand were wrong in eight of thirteen places

Every text token in `tokens.css` shipped with its contrast ratio in a comment. Checking them
afterwards: **eight were wrong** — seven understated (harmless) and one **overstated**
(`--rg-medium-deep` claimed 5.0:1, actually 4.84:1).

Correcting the numbers would have been the small fix. The right fix was to stop asserting them: the
ratios are now **measured in the browser** from the tokens as the cascade actually resolves them, in
both themes, and the test states the **floor** rather than the value — floors survive a palette
tweak, hand-copied numbers do not.

Measuring immediately found something a comment never would: **the brand's own `--rg-medium-deep`
(`#86700a`) misses AA in both places the brand puts it** — 4.44:1 on its own 16% tint and 4.38:1 on
the canvas — while passing on white (4.84:1). The brand asserts every `-deep` step "passes AA as
text on light grounds" and specifies severity pills as tint fill with 700-step text; for this one
step those two statements are not jointly true. Darkened one step in the same hue to `#7f6a09`
(4.85 / 5.29 / 4.79) and recorded as ADR-0075 §5.2b — the only brand-supplied value this work
changes.

The test also over-reached once, in my direction rather than the brand's: it held `--rg-line-strong`
to the 3:1 non-text floor. WCAG 1.4.11 covers information required to identify components and their
states; **a hairline between table rows is decorative separation**, and enforcing 3:1 on it would
mean a grey dark enough to turn every table into a grid of boxes. The pair was removed with the
reasoning written next to it, so the next person does not re-add it.

## Judgment calls recorded rather than improvised

The Traps section is explicit that when the brand is silent, the call must be made openly, because
*"an undocumented improvisation becomes precedent the next person can't question."* Three, all in
ADR-0075 §5:

1. **The brand defines no success hue.** Borrowed from the regulAIt **Governed** ramp — the same
   remedy, and the same source family, the sibling app chose.
2. **Radii and spacing** are ours; the brand says nothing about either.
3. **Product accent = Governed**, because this app's own shell has called itself "governed" since
   before the brand package existed. That is an existing choice being honoured, not a new one. It
   paints the lockup descriptor and nothing else — never an action, never a severity.

Also derived rather than duplicated: the page-header breadcrumb reads the nav group from the shell's
own `ADMIN_GROUPS` map, so ~60 admin screens each got a correct trail without any of them
hand-passing one, and the trail cannot drift from the navigation it describes.

## Verified

- All 12 brand-contract specs green in a real browser, including zero console errors across 15
  routes in both themes.
- Both themes screenshotted for every page archetype and inspected by eye — not merely captured.
- `tsc --noEmit` clean; SPA build clean with fonts fingerprinted.

## Open

1. **The `--rg-*` migration is unfinished.** Legacy aliases remain at ~500 call sites. They are
   correct, but the contract's promise — redefine the values, keep the names, shared components
   carry over untouched — is only fully realised once components name `--rg-*` directly.
2. **List-page / drawer / table conventions are adopted as utilities and page-header structure, not
   as a re-layout.** UI Structures describes a Bootstrap/DashForge DOM; this is React with CSS
   modules. The contracts port, the class names do not. Re-cutting every list page onto the
   one-card-with-toolbar pattern is separate, larger work.
3. **Contrast is asserted by construction, not measured** — every pair carries its computed ratio in
   a comment; no automated sweep runs.
4. The wordmark rule is enforced on 15 routes. Copy added to an unvisited route can still drift;
   widening the list is the remedy, and that list is the honest limit of the guarantee.

## Standing, and unchanged by this session

**No model provider is connected** — the owner's key remains parked by standing instruction and was
not requested. Nothing in this session touched governance, entitlement, audit or cost semantics.
