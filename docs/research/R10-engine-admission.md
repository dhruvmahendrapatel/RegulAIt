# R10 — Engine admission (research task G19, ADR-0187)

G19 asks, per engine, the facts each engine's PR needs before it can be admitted. **Only the promptfoo section is
written so far**, by Claude during B5-P (2026-10-08), because G19 (assigned to Codex) had not started and the
promptfoo PR must not block on it. The modelscan and garak sections remain G19's.

Method for the promptfoo section: every fact was read from the pinned package itself, offline from the npm registry
tarball (`npm pack promptfoo@0.123.1`, integrity `sha512-9WzFeH6L…x0Cbg==`, `gitHead`
`34f74d34e140b5e17d23770dfb2340057b1936b8`), i.e. from its bundled `dist/src` code and `package.json`, and from the
lockfile npm resolves for it. Runtime facts were then checked by running that exact package (installed from the
committed lockfile, `npm ci --omit=optional --ignore-scripts`) through the RegulAIt adapter against a local fake
gateway, with a preload that records and blocks every non-loopback connect and lookup
(`packages/engine-promptfoo/src/promptfoo-real.test.ts`). No image was built (no Docker daemon in this environment)
and no vendor service was contacted. Vendor and model names are deliberately not repeated here.
